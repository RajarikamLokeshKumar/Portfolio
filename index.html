SHEET 01 / ABOUT

Infrastructure that ships fast and stays up.

I'm a DevOps engineer at PruTech Solutions, where I own the path code takes from a Git commit to a running service in production — Jenkins pipelines, security scanning, containerization, and GitOps deployment to Kubernetes on AWS.

My approach is to treat delivery as a system, not a series of manual steps. I automate provisioning with Terraform so infrastructure stays consistent across environments, use Argo CD and Helm so Kubernetes deployments are declarative and repeatable, and build SonarQube and Trivy checks into the pipeline so security scanning happens before code reaches a cluster, not after.

The part of the job I take just as seriously is what happens after deployment — monitoring, incident response, and root cause analysis in live Linux environments. A pipeline that ships fast but leaves you blind in production isn't finished. I build in observability with Prometheus, Grafana, and CloudWatch from the start.
